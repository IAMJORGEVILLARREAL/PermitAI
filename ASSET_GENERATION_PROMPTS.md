# BuildScope Asset Generation Prompt Library

This library defines a cohesive image system for **BuildScope**, the quiet tool construction professionals trust.

BuildScope reads construction plans, creates quantified scope packages, matches verified subcontractors, supports sealed bidding and award, and tracks source-linked permit compliance through closeout.

The locked brand theme is **Minimal Industrial**.

---

## 1. Brand North Star

BuildScope is inspired by fabrication shops, engineering documentation, precision manufacturing, architectural specification books, and industrial materials—not conventional construction branding.

Everything is reduced to its essential form.

Nothing decorative. Nothing loud. Every element has a purpose.

Imagine Apple designing software for Skanska, Turner, DPR, or Bechtel:

- Industrial
- Minimal
- Architectural
- Monochrome
- Purpose-built
- Quietly confident
- Less startup, more tool

Creative references include Apple hardware, Teenage Engineering, Muji, Braun, Dieter Rams, Nothing, Aesop, Figma, Linear, Swiss editorial design, Japanese industrial design, mechanical engineering manuals, and material sample libraries.

BuildScope should **not** feel like:

- A construction company
- A generic SaaS startup
- A cyberpunk AI product
- A rustic workshop
- A rugged workwear brand
- A playful productivity app
- A glossy luxury object

## 2. Locked Visual System

### Color

- Carbon Black — `#111111`
- Graphite — `#242424`
- Steel — `#5E5E5E`
- Concrete — `#A7A7A7`
- Fog — `#EAEAEA`
- Paper — `#F8F8F6`
- Highlight Lime — `#C7F000`

Safety Lime is inspired by laser levels, surveying equipment, high-visibility layout markings, industrial measurement, and CAD highlight layers.

**Lime must occupy no more than 3–5% of any composition.** It may indicate only:

- Current selection
- Important action
- Current project
- Status

Never use lime as a full background, large button fill, broad gradient, or decorative glow.

### Typography

- Display: Geist, Satoshi, or Neue Haas Grotesk
- Body: Inter
- Technical labels: Geist Mono

Mono is reserved for permit numbers, code references, dimensions, revision IDs, coordinates, and drawing labels.

Generated imagery should avoid important text. Add final typography in the application or design tool. If text is essential, limit it to short labels such as:

- `BUILDSCOPE`
- `PROJECT 0247`
- `A1.01`
- `REV 03`
- `DIV 26`
- `VERIFIED`

### Materials

- Brushed aluminum
- Powder-coated steel
- Smooth unfinished concrete
- Black rubber
- Uncoated paper
- Matte acrylic
- Laser-cut acrylic
- Embossed cardstock
- Anodized aluminum

Everything is matte. Never glossy. Never chrome.

### Graphic language

Use only restrained, functional devices:

- Hairline rules
- Registration marks
- Dimension arrows
- Crosshairs
- Tiny coordinate systems
- Measurement ticks
- Serial numbers
- Revision IDs
- Barcode labels
- Material tags
- Specification tables
- Small corner brackets
- Tiny alignment dots
