A1.01 / Intake

One pass from plan set to signed subcontract.

01

Ingest the set

Upload the full package. Sheets are classified and read, then the site address is overlaid with zoning, flood, wetland and historic-district data.

02

Decompose the scope

Vision models detect walls, openings, fixtures, panels and structural members, then quantify them into packages by MasterFormat division.

03

Post the package

You confirm the quantities and set a deadline. Matching ranks subcontractors on license, radius, bonding, capacity and prior performance.

04

Level and award

Sealed bids open at the deadline. Compare them side by side, award, and the subcontract generates with the scope attached as an exhibit.

05

Track the permits

On execution, that sub's trade permits enter the project ledger with their name on them. Nothing gets chased down after the fact.

A2.01 / Scope

Every quantity points back to a line on the drawing.

The takeoff is not a written summary. Each detection is a structured object with a type, coordinates and a confidence score, so a quantity can always be traced to the geometry that produced it.

Generative models never write the permit list.

T1.01 / Trust

What the output is, and what it is not.

Rules engine

Deterministic, not generated

Permit requirements execute against a versioned rule graph. Generative models are confined to interpreting unstructured plan notes.

Citations

Linked to adopted code

Every requirement carries its issuing authority, the scope tag that triggered it, and a link to the municipal section in force.

Audit log

Immutable and versioned

Every user action, contract event and rule version used is recorded, and cannot be rewritten after the fact.

Isolation

Walled between tenants

Bids, contract values and pricing never cross between competing organizations. Enterprise adds dedicated schema isolation.

Encryption

AES-256 and TLS 1.3

Data is encrypted at rest and in transit. SOC 2 Type II certification is targeted within twelve months of launch.
