# BuildScope Brand Theme — "Minimal Industrial"

> The quiet tool professionals trust.

---

## Core Idea

BuildScope is the quiet tool professionals trust.

Inspired by fabrication shops, engineering documentation, precision manufacturing, and industrial materials—not construction branding.

Everything is reduced to its essential form.

Nothing decorative.

Nothing loud.

Every element has a purpose.

Imagine if Apple designed software for Skanska, Turner, DPR, or Bechtel.

## Color System

The entire brand lives in grayscale.

One accent color exists only to guide attention.

### Primary

| Name | Hex | Role |
|---|---|---|
| Carbon Black | `#111111` | Primary text, structure, heavy surfaces |
| Graphite | `#242424` | Panels, deep surfaces |
| Steel | `#5E5E5E` | Secondary text, labels |
| Concrete | `#A7A7A7` | Tertiary / disabled |
| Fog | `#EAEAEA` | Soft surfaces, dividers |
| Paper | `#F8F8F6` | Page background, paper stock |

### Highlight

| Name | Hex | Role |
|---|---|---|
| Safety Lime | `#C7F000` | Selection, important action, current project, status |

Why Safety Lime:

- Laser levels
- Surveying equipment
- High-visibility layout markings
- Industrial measurement
- CAD highlight layers

Unlike startup green, it is unmistakably industrial. It pops against monochrome.

**Rule:** Never use more than 3–5% lime in any composition. It should feel precious.

Never use lime as:

- Full backgrounds
- Entire button fills
- Broad gradients
- Decorative glow

## Typography

Huge typography. Massive whitespace. One font family system.

| Role | Fonts | Use |
|---|---|---|
| Display | Geist, Satoshi, or Neue Haas Grotesk | Large headlines |
| Body | Inter | UI and editorial body |
| Mono | Geist Mono | Permit numbers, code references, dimensions, revision IDs, drawing labels |

## Graphic Language

Extremely restrained.

Only recurring elements:

- Hairline rules
- Registration marks
- Dimension arrows
- Crosshairs
- Tiny coordinate systems
- Measurement ticks
- Serial numbers
- Revision IDs
- Barcode labels
- Material tags
- Specification tables
- Small corner brackets
- Tiny alignment dots

Everything should feel engineered.

---

## Iconography

- Ultra-thin outline icons
- Perfect geometry
- No fills
- No rounded playful shapes
- Feels laser cut
- Inspired by industrial equipment manuals

---

## UI Language

- Large spacing
- Minimal borders
- Almost no shadows
- Cards disappear
- Interfaces feel carved from one surface
- Lots of breathing room

Accent lime only indicates:

- Current selection
- Important action
- Current project
- Status

Never entire buttons.

## Product Context

BuildScope turns construction plans into quantified scope packages, matches verified subcontractors, runs sealed bidding and award, and carries source-linked permit compliance through closeout.

Trust principle: AI interprets unstructured plan content; deterministic rules and source-linked citations establish regulatory ground truth.
