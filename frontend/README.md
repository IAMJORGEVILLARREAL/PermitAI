# PermitAI — Hackathon Demo

**Permits + local subcontractors in one loop.**

Mock-data shell for demos. No auth, no real AI backend, no Places API key required.

## Run

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo script (~2 min)

1. **Start demo**
2. Click a scenario (Phoenix TI / Austin kitchen / Denver ADU) — or drop any file
3. Watch the 4-stage “analysis”
4. Show **permits + docs**, then **subs with reviews**
5. Click **Find Electrical →** on a permit, open reviews, **Invite / Request quote**
